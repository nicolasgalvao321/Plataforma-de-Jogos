#Plataforma de Jogos

Uma plataforma web interativa desenvolvida com HTML, CSS e JavaScript, que reúne diversos jogos criados por mim em um único ambiente, com navegação dinâmica e sistema de feedback.

---

## Funcionalidades

- Acesso a múltiplos jogos em um só lugar  
- Navegação dinâmica sem recarregar a página (uso de iframe)  
- Jogos desenvolvidos manualmente  
- Formulário de feedback integrado  
- Layout responsivo (funciona no celular e desktop)
